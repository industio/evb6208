# IDO-EVB6208

> An evaluation board based on the Rockchip RK3562 (Quad-core ARM Cortex-A53, up to 2.0GHz), supporting up to 8GB of memory, integrating an independent NPU for lightweight AI applications, and supporting PCIe 2.1, USB 3.0 OTG, dual Ethernet ports, and multiple video I/O interfaces. It is suitable for scenarios such as IoT gateways, tablet PCs, smart homes, educational electronics, industrial displays, and industrial control.

## ✨ Core Features

- **High-Performance SoC**: 4 × Cortex-A53 (2.0GHz), integrated ARM G52 2EE GPU,built-in 1 TOPS NPU
- **All-Round Connectivity**: 2 × Gigabit Ethernet ports (RGMII + PCIe), Wi-Fi 6 (802.11ax) + Bluetooth 5.4
- **Rich Multimedia**: 1 × MIPI DSI / HDMI (multiplexed), 2 × 4-Lane MIPI CSI, 4K 30fps H.265/H.264 decoding, 13M ISP
- **Software Ecosystem**: Linux Kernel 5.10 SDK, supporting Ubuntu Base/ Debian / Buildroot / Android;
- **Core Board + Base Board Architecture**: Core board model IDO-SOM6208-B1
